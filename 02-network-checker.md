# Python Network Checker (Python tarmoq tekshiruvchisi)

## About the Project (Loyiha haqida)

This is my first Python project in cybersecurity learning.
(Bu mening kiberxavfsizlikni o‘rganishdagi birinchi Python loyiham.)

The program checks basic network information on my computer.
(Dastur kompyuterimdagi asosiy tarmoq ma'lumotlarini tekshiradi.)

## Features (Dasturning imkoniyatlari)

1. Detects computer hostname. (Kompyuter nomini aniqlaydi.)
2. Displays local IP address. (Lokal IP manzilni ko‘rsatadi.)
3. Displays router IP address. (Router IP manzilini ko‘rsatadi.)
4. Checks connection to the router. (Router bilan aloqani tekshiradi.)
5. Checks internet connectivity. (Internet aloqasini tekshiradi.)

## Technologies (Foydalanilgan texnologiyalar)

- Python 3.14.3
- Socket module (Tarmoq bilan ishlash moduli)
- Subprocess module (Tashqi buyruqlarni ishga tushirish moduli)
- Windows CMD (Windows buyruqlar oynasi)

## What I Learned (Nimalarni o‘rgandim)

- Basic Python programming (Python dasturlash asoslari)
- IP addresses (IP manzillar)
- Network connectivity (Tarmoq aloqasi)
- Ping command (Ping buyrug‘i)
- Router and DNS concepts (Router va DNS tushunchalari)
