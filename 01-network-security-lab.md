# Network Security Lab

## 1. Project Goal
Learn basic network security and understand how computer networks work.

## 2. IP Configuration

Command:
ipconfig

My findings:
- IPv4 Address: 192.168.1.65
- Subnet Mask: 255.255.255.0
- Default Gateway: 192.168.1.1

## 3. Network Connectivity Test

Command:
ping 192.168.1.1

Result:
- Packets sent: 4
- Packets received: 4
- Packet loss: 0%
- Average response time: 4 ms

Conclusion:
My computer successfully communicated with the router.

## 4. DNS Analysis

Command:
nslookup google.com

What I learned:
- DNS translates domain names into IP addresses.
- IPv4 uses A records.
- IPv6 uses AAAA records.

## 5. Conclusion

I completed my first network analysis laboratory.
I learned basic IP configuration, network connectivity and DNS.
